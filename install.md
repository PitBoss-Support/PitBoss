# Install

PitBoss is a Manifest V3 extension for **Chrome** and **Brave** on the desktop. Firefox is not supported yet.

The friends and family beta is an **Unlisted** listing on the Chrome Web Store. It is invite-only: it does not appear in store search, so you need this direct link.

<p class="hero-actions">
  <a class="btn btn-primary" href="https://chromewebstore.google.com/detail/pitboss/dpklofklabanhonajhhiefdjdeoiaeco">Install from the Chrome Web Store</a>
</p>

[https://chromewebstore.google.com/detail/pitboss/dpklofklabanhonajhhiefdjdeoiaeco](https://chromewebstore.google.com/detail/pitboss/dpklofklabanhonajhhiefdjdeoiaeco)

## Chrome

1. Open the link above in Chrome.
2. Choose **Add to Chrome**.
3. Confirm the install.

## Brave

Brave can install this extension from the Chrome Web Store the same way.

1. Open the link above in Brave.
2. Choose **Add to Brave** (the store install button).
3. Confirm the install.

On first install, PitBoss opens its Help page at the Welcome section.

If you previously loaded PitBoss unpacked, remove that copy first so you do not run two extensions. See [switching from an unpacked install]({{ '/faq/' | relative_url }}#switching-from-an-unpacked-install).

## After install

PitBoss runs only on `boardgamearena.com`. Open a Heat: Pedal to the Metal table — the panel does not appear in the lobby.

If card counts look wrong or the panel lost sync, reload first, then click Reset if it stays wrong. See [troubleshooting in the FAQ]({{ '/faq/' | relative_url }}#the-panel-looks-wrong-or-card-counts-do-not-match).

## Fallback: load unpacked

For contributors, or if the store link is unavailable, you can load the extension unpacked:

1. Open the Extensions page (`chrome://extensions` in Chrome, or `brave://extensions` in Brave).
2. Turn on **Developer mode**.
3. Choose **Load unpacked**.
4. Pick the PitBoss folder.

Remove any unpacked copy before you install from the store.
