# Support / Contact

## Email

[pitbosssupport@gmail.com](mailto:pitbosssupport@gmail.com)

Unlisted friends-beta testers can use this address.

## GitHub Issues

The extension's **Report a bug** link opens a new issue on this repository: [https://github.com/PitBoss-Support/PitBoss/issues/new](https://github.com/PitBoss-Support/PitBoss/issues/new).

You can also open an issue from here. Please use the **bug report** template. It asks for:

- PitBoss version
- BGA table number
- What happened
- Optionally, a **Copy Diagnostic Dump**

[Open a bug report](https://github.com/PitBoss-Support/PitBoss/issues/new?template=bug_report.yml)

## Diagnostics for bug reports

From Options → Help, use **Copy Diagnostic Dump**.

You can also **Shift+click the PitBoss title** on the panel to show diagnostics for bug reports.

## Before you write

If card counts look wrong or the panel lost sync:

1. Reload the BGA tab.
2. If it stays wrong, click **Reset** (clears saved tracking for that table and reloads).

See the [FAQ]({{ '/faq/' | relative_url }}#the-panel-looks-wrong-or-card-counts-do-not-match) and [known limitations]({{ '/known-limitations/' | relative_url }}).
