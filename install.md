# Install

PitBoss is a Manifest V3 extension for **Chrome** and **Brave** on the desktop. It is not on the Chrome Web Store yet. A store listing is planned later, as a **private beta** first.

Until then, install it unpacked.

## Load unpacked

1. Open the Extensions page (`chrome://extensions` in Chrome, or `brave://extensions` in Brave).
2. Turn on **Developer mode**.
3. Choose **Load unpacked**.
4. Pick the PitBoss folder.

On first install, PitBoss opens its Help page at the Welcome section.

## After install

PitBoss runs only on `boardgamearena.com`. Open a Heat: Pedal to the Metal table — the panel does not appear in the lobby.

If card counts look wrong or the panel lost sync, reload first, then click Reset if it stays wrong. See [troubleshooting in the FAQ]({{ '/faq/' | relative_url }}#the-panel-looks-wrong-or-card-counts-do-not-match).
